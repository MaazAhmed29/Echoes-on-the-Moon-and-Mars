# Echoes on the Moon & Mars

An interactive, story-driven web experience built by **Team Warrior of Space** (Maaz Ahmed) for the **2026 NASA Space Apps Challenge** (*Abandoned but Not Forgotten*).

## What It Does
- **Six Iconic Missions:** Explore Apollo 11 Eagle Descent Stage, Apollo 15 Lunar Roving Vehicle, Mars Pathfinder & Sojourner, Mars Rover Opportunity, InSight Mars Lander, and Ingenuity Mars Helicopter.
- **Clear Mission Dossiers:** View crew and mission teams, exact dates, resting coordinates, planned vs. actual durations, why and how each craft was built, and what went wrong.
- **Real NASA Photography:** Fetches live, public-domain mission images from the NASA Image and Video Library API with a full-screen photo viewer.
- **Explorer Quiz:** Test your knowledge with a 10-question randomized quiz featuring three astronaut ranks and recent score tracking.

## NASA Data & Tech Stack
- **NASA Data:** [NASA Image and Video Library API](https://api.nasa.gov/) (`images-api.nasa.gov`)
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript, HTML5 Canvas starfield
